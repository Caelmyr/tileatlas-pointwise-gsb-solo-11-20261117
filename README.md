# TileAtlas

TileAtlas 是本地游戏图像资产工作台。入口 http://127.0.0.1:8914 。点击“装载合成演示”得到6张透明精灵；它们是代码绘制的合成素材。

正常流程：建立图集、上传PNG/JPEG/WebP、编辑精灵、生成图集、下载PNG/UV JSON/逐张重建图像；可保存和恢复项目ZIP。精灵编辑支持透明边界裁剪、阈值、旋转、镜像、最近邻或平滑缩放和源画布归一化轴心。可开关参与打包、检查重复、查看联系表、平铺预览与边界接缝统计。矩形打包使用短边优先的贪心空闲矩形算法，支持可选90度旋转、间距和边缘像素外扩。预览和交付共享布局与渲染器，UV清单按原图角点顺序给出坐标。

选中精灵后可另行生成贴合透明轮廓的三角网格：轮廓阈值决定哪些alpha像素计入实体，简化程度用Douglas–Peucker收紧轮廓点。覆盖预览把网格多盖的像素标红、漏掉的像素标蓝并画出三角形边，统计同时给出覆盖像素、多盖/漏掉数量和IoU。网格按像素角点追踪边界环，互不相连的孤立小块各成独立环，内部透明孔保持负向环，三角化只保留偶奇内部的三角形，因此不会跨孔连面或把孤立块连成一体。完全透明的精灵得到0顶点、0三角形的空网格，矩形打包与重建照旧。下载的图集ZIP在启用网格时附带 meshes.json：每个精灵含顶点、三角索引、图集UV、原画布顶点、逐精灵三角形绕序、阈值/简化参数与孔洞/孤立块统计；UV已计入间距外扩、缩放、裁边和可选90度装箱旋转，canvas_vertices 可还原到未经旋转镜像的原画布坐标。普通矩形导出不启用网格时保持原格式。

最多128个精灵；单图24MB、4096边长、800万像素；单图集128–2048的2次幂边长。不承诺最优装箱，不支持多页、动画轨道、九宫格、SDF或引擎专有导入格式。轮廓网格不适合噪声型alpha（例如整图随机半透明）：边界边超过15万、顶点超过4万或三角形超过8万时直接报错并提示提高简化程度或调整阈值，不静默降级。外扩只复制RGBA边缘，不做透明区颜色传播。源图像与变换参数分别保留，包内重建是处理后源画布，不等于未经变换的原文件。

## 启动

`docker compose up -d --build`。数据放独立命名卷 `solo14-tileatlas_tileatlas_data`；重建容器可保留数据。普通Python运行安装requirements.txt后执行 `python app.py`，可设置PORT与TILEATLAS_DATA_DIR。Dockerfile复用已有图像运算运行时，requirements同时支持Python3.11/3.12。

`/prepare` 是复用自solo_13的自有image_lab图像准备工具，支持照片载入、色彩转换、曝光/焦点等合成、遮罩、局部调整、比较与图像导出。需要从摄影原料提取纹理时，可先处理并下载图像，再上传到图集。此工具保留原有工作流；TileAtlas新增的业务模块是tileatlas/、atlas页面及图集接口，不复用版次/审校/印前业务。

## 源码

`tileatlas/raster.py` 负责透明图像和边界；`packing.py` 负责装箱/渲染/UV/重建；`mesh.py` 负责轮廓环追踪、约束三角化、覆盖统计与网格交付；`catalog.py` 负责源素材及修订；`delivery.py` 负责图集与工程包；`demo.py` 负责合成演示；`__init__.py` 负责HTTP与页面入口。`image_lab/` 是自有复用图像准备包。`scripts/count_backend.py`可复算Python有效代码，前端和统计工具不计后台。
